## 七、取象规律（观象制器，取象前必读）

### 总原则

**必须进行阴阳爻推理，不能依靠万物类象。** 取象的唯一来源是本节的阴阳爻推理；第八节万物类象表只起辅助作用（提示候选象、印证结果），不能直接查表取象。

**阳动阴静，阳刚阴柔。** 取到一个卦的卦象时，**必须根据卦的阴阳爻结构检验所取之象是否合理**：每一个象都要能从爻画结构里推导出来（爻位、阴阳、动静、刚柔、内外、上下、虚实、五行），不可死记硬背，不可随意取象。

**当下产物远超古代**：现代事物（公交车、大巴车、火车、互联网、手机、电梯等）皆可入象，但取象一定要有规律——古代没有的事物，按同一规律推导出它的现代对应物（例如坤为大輿，现代对应公交车、大巴车、火车这类承载众人的载具），再结合卦主的具体问题筛选。

### 成像推导示例（观象制器的完整示范）

**乾卦——三爻纯阳，刚健不息（乾为天）**
- 爻画结构：纯阳 → 刚健、动、纯粹、精华
- 由结构推象：天（至刚至大，运动不息）→ 圆（大体圆运动不息）；天生万物 → 万物之始；天笼罩万物如君一览天下 → 君；父主管一家 → 父；天清地浊、纯阳之卦 → 精华为纯粹；汲取精华之物 → 玉；纯粹之物为贵 → 金、冰；一天之始为初生之阳，其色大赤 → 大赤色；刚健者 → 马（能持久奔跑的马；良马、瘠马、驳马等为古代相马内容，不必细分）；果树积累所结的精华 → 果木
- 衍生之象：君为独裁、为寡、为威严 → 寡、威严；乾位西北 → 寒；家中极具威严之人为老人 → 老；独裁之下百姓压抑 → 压抑；天囊括万物 → 统一；纯阳刚健 → 任性；独裁迫害 → 惩罚

**坤卦——三爻纯阴，柔顺承载（坤为地）**
- 爻画结构：纯阴 → 阴柔、静、承载、孕育
- 由结构推象：纯阴 → 浑浊，混杂万物 → 地；地承载、孕育万物 → 承载、孕育；孕育之人为母 → 母；孕育之物分散各地 → 广布；承载食物的器皿 → 釜；纯阴主阴柔 → 吝啬；万物均生于地 → 均；牛能载人、能装载农具 → 牛（子母牛强调孕育关系）；大輿承载许多人或物 → 大輿（现代对应：公交车、大巴车、火车）；地为承载、为厚德、为传承 → 文化；地为散布为均 → 众；承载工具的柄 → 柄
- 衍生之象：阳动阴静 → 静、行动迟缓；交浊混乱 → 优柔寡断；坤为阴柔与乾相反 → 懦弱、逆来顺受；人身体承载食物之处 → 腹；神佛为安抚民间大众之物 → 敬奉神佛

**震卦——一阳动于二阴之下（震为雷）**
- 爻画结构：下阳上两阴 → 一个动的东西藏在静物之下 → 蓄势而动、即将突破
- 由结构推象：雷 → 惊（雷产生惊扰）；蓄势待发、游藏于水中等待突破 → 龙；一天太阳刚突破天际，天地交杂之色 → 玄黄；刚生长出的事物 → 青色；一阳在下动、上方两阴 → 前方开阔 → 大涂；震为坤初爻变 → 长子；阳爻动于初、主急于进取 → 决躁；为青色为初生 → 苍莨竹；上虚下实 → 芦苇；躁动之马、蓄势之马多嘶鸣 → 善鸣；善动善鸣 → 作足、弁足；一阳爻藏于阴爻之下 → 土中之物（花生等）；为躁动为蓄势 → 健；植物成长营养厚实储蓄多 → 蕃鲜
- 衍生之象：决躁而初变、进取而刚健 → 转折（主动追逐目标的转折、突然的转折）；为进取 → 上升、进步；即将突破 → 出发、兴起、新生；为刚健为进取 → 勇敢；为惊扰为善鸣 → 冲突、夸大无礼、出征、声响

**巽卦——一阴伏于二阳之下（巽为风）**
- 爻画结构：下阴上两阳 → 上面的实物向下延伸，下面的阴爻使阳爻变得更实 → 木；底下无根基 → 风
- 由结构推象：风无孔不入、长久影响 → 潜移默化；缓慢的一步一步变形 → 绳直；绳直制木 → 工艺、工作、工匠；风无色无味、高空风吹云动 → 白；乘风而上 → 高；无根基则飘忽不定 → 进退；为木无根基 → 摘下来的木果；为乾卦初爻变 → 能获利多倍；为风为根基不稳 → 浮躁
- 衍生之象：阳爻为明朗，外面明朗 → 干净整齐；向下延伸、无孔不入 → 渗透；顺风而呼 → 传达、捷报；为风根基不稳 → 轻浮、多欲、幻觉、涣散；由外向内渗透 → 贪欲、权谋、薄情

**坎卦——一阳陷于二阴之中（坎为水）**
- 爻画结构：上下阴、中一阳 → 外静内动、外虚中实；阳在核心，阴从阳动
- 由结构推象：阳为生命居核心 → 水、生命之源、本源（受精卵、DNA，测病可为血液病、遗传病）；坤地中间一阳在动 → 大地之中流动之物 → 沟渎（河道、水道）；外静内动 → 隐伏（偷偷做事、欺骗、暗中行动）；核心在动、外形随之变 → 矫揉（可塑性：塑料；水随环境变形）→ 弓轮（制作要经矫揉）；阳陷阴中、周围屈从于我而我沉溺其中 → 险陷 → 加忧、心病、痛；内部在活动 → 内心活动、思考、谋划；明在内、信息朝我汇聚 → 耳；水在人体 → 血 → 血液流动交换 → 交易；血气充盈 → 面赤；阳坚居中、贯通上下 → 脊梁、美脊；阳动居中 → 亟心（性急、难驾驭）；阳气走到临近终点 → 劳（下首、薄蹄、曳）；险 → 舆多眚（颠簸坎坷，对比坤大舆的安稳）；阳坚居中连接上下 → 通（桥梁、通道、交通、中介、脊柱、互联网）；阳明被阴暗包裹、居核心唯一 → 月（不是星）；四面力量向核心靠拢 + 外静内动 + 月借日光 → 盗；内阳为刚 → 坚多心（荆棘、枣木）、核、种子
- 衍生之象：核心在动 → 枢机、核心、逢迎、谄媚、奸佞、弯曲、灵活多变；能量朝自己汇聚 → 汲取、征收（案例三）；暗中行动 → 暗算（案例四）；陷 → 困境、忧虑

**离卦——一阴附于二阳之中（离为火）**
- 爻画结构：上下阳、中一阴 → 外明内暗、外实中虚、外坚内柔
- 由结构推象：外阳明朗、照耀外界 → 火、日 → 明朗、光芒、光色；能量朝外散发 → 付出、牺牲；外明 → 电（光影，与雷主声音区分）；外实中虚、只有外在现象没有实体 → 光学现象（霓虹、电光）、书画、文字；坚硬外壳护着柔软身躯 → 甲胄 → 保护 → 戈兵（保卫国家者）；外坚内柔 → 鳖、蟹、蠃、蚌、龟；得坤中气、突出容纳的阴性 → 大腹；中间阳爻丢失、水分与生命力被抽干 → 科上槁（中空枯木，枯枝坠地占取此象）；外阳明朗让外界明朗 → 目（须借外光，外界越亮看得越清）
- 衍生之象：目 → 看、被看、被盯上（案例三"望"字）；文字 → 文书、上书、弹劾、证件、契约（案例四）；外在展示 → 图形图案、包装、广告、宣传；只有外表没有实体 → 虚名、虚饰；外明 → 显现、曝光

**艮卦——一阳止于二阴之上（艮为山）**
- 爻画结构：下两阴、上一阳 → 阳在最上爻（结果、表面、末端的位置）；坤卦上爻变阳
- 由结构推象：大地之上最高大凸显之物 → 山 → 凸显、庞大、高耸、凸起；震的覆卦，震阳在下开辟主路 → 艮从旁开辟小路 → 径路；大者为山、小者为石 → 小石；阳实在最上爻、为表面边缘 → 边界 → 门阙（门庭、界碑）；阳实在末尾、植物最后结出的果子 → 果蓏 → 成果、结果、结论、结束、尽头；阳动走到末端、动到头了 → 止（从动到停，区别于坤一直不动的静）→ 制止 → 阍寺（守门人）、狗（看家护院）；阳主形在最上、身体末端 → 指 → 拿持、控制；上爻明朗在末端 → 指向 → 方向、答案、目标、路标；阳实在外且显著 → 坚多节（竹、甘蔗，外表坚硬有凸起）
- 衍生之象：止 → 停驻、卡住、守（案例五"住割于途"）；明在结果之位 → 结论、旨归、归宿（强调指向性，不具代表性、象征性，区别于乾）

**兑卦——一阴开于二阳之上（兑为泽）**
- 爻画结构：下两阳、上一阴 → 阴在最上爻；乾卦上爻变阴
- 由结构推象：阴气最后成形之物 → 泽 → 阴润于阳 → 润泽；润泽 → 悦（胸中郁结消散、久旱逢甘露，不单指开心）；上爻开口、感通天地 + 取悦鬼神 → 巫；上爻阴为开口、人身最上方开口最大处 → 口舌（实指）→ 凡感知外界的窍穴（目、鼻、耳）→ 感知、摄取；阴在末尾、结果不确定 → 口舌（虚指：分歧、意见不统一，对比艮阳在末尾为结果统一明确）；上爻阴主断裂、破坏自外而内 → 毁折（对比巽下爻断裂为腐败，自内而外）；柔依附刚之上 → 附；阳爻主进、要冲开顶端阴爻、静积蓄到极致 → 决（决堤）；时在正秋、有杀伐 → 刚卤（盐碱地、不肥沃之地）；阴主从而在最上 → 妾、偏室、二把手、副职；外柔内刚 → 羊（看起来柔顺、内里争强好斗）
- 衍生之象：开口 + 毁折 → 咬、口舌谗毁、批评（案例三虎咬落兑）；开口 → 饮食、谈判；口窍通于外 → 肺、咽喉（案例五肺疾）

### 阴阳爻推理方法（从案例提炼，取象时逐条检验）
只看单个三爻卦（经卦）的爻画，不把上下卦叠成六爻卦来取象。

1. **阴阳的基本性质**：阳主动、明朗、实、坚、刚、进；阴主静、晦暗、虚、柔、含容、断裂、开口、分叉。每个象都要落到某一爻的阴阳性质上。
2. **爻位定含义**：初爻为开始、下方、根基；中爻为核心、内部；上爻为结果、末端、表面、边缘、外界。同一种爻放在不同位置，象完全不同：
   - 阳在初（震）：动于下 → 起始、出现、开辟主路、足（身体下方能自如运动的部位）
   - 阳在中（坎）：动于核心 → 本源、内心活动、贯通、可变性
   - 阳在上（艮）：动到末端 → 止、结果明确、成果、边界、指向、手（身体上方能自如运动的部位）
   - 阴在初（巽）：下方分叉、根基断裂 → 股（大腿）、无根、自内而外的腐败
   - 阴在中（离）：核心空 → 中虚、只有外表没有实体、枯槁
   - 阴在上（兑）：上方开口、断裂 → 口、窍穴、自外而内的毁折、结果不确定（分歧）
3. **内外看动静虚实**：外阴内阳（坎）→ 外面看起来静、里面在动 → 隐伏、暗中行动、谋划；能量朝自己汇聚 → 汲取、盗。外阳内阴（离）→ 外面明朗、里面空 → 照亮外界、目、图文；能量朝外散发 → 付出、牺牲。外坚内柔 → 保护（甲胄、龟蟹）。
4. **阳爻的运动方向**：阳主动，看它往哪里走、走到了哪一步。震阳在下往上冲 → 进取、突破；巽阳在上往下走 → 渗透、深入、下行；艮阳到顶动到头 → 止。方向决定取象的边界：巽阳是往下走，所以巽取不出"升官、上进"（案例四存疑），只能取渗透、调动下行、深入地方（案例三）。
5. **看卦从哪里变来**：震巽是乾坤初爻变，代表事物转折、改变的起始点（气象）；艮兑是乾坤上爻变，代表事物的成形阶段（物象），刚者为山、柔者为泽。坎离得乾坤中气（坎得天中之阳、离得坤中气突出容纳 → 大腹）。覆卦也可推象（艮为震的覆卦：震开辟主路，艮从旁开辟小路 → 径路）。
6. **相近的象要对比区分**：两卦都能取的象，比较阴阳位置找出差别，再看哪个合乎所问：
   - 坎为源头（本源，微妙看不见，如受精卵、心中的谋划）vs 震为开始（出现，明朗表现出来，如孩子落地、付诸行动）
   - 坎为变通（自身灵活，核心带动外形）vs 震为转折（趋向的转变）
   - 艮为止（从动到停，有制止义）vs 坤为静（一直不动）
   - 艮为动的结束（停止）vs 兑为静的结束（决：积蓄到极致要冲破）
   - 艮阳在末尾为结果统一明确 vs 兑阴在末尾为结果不定、分歧
   - 兑为毁折（破坏，自外而内）vs 巽为腐败（腐烂，自内而外）
   - 乾为象征（凝练、有代表性，如 logo）vs 离为展示（包装、广告）vs 艮为指向（路标，无象征性）vs 坤为蕴藏（散布、隐晦，如作品承载理念）
   - 离为目（明在外，靠外光，外越亮看越清）vs 坎为耳（明在内，信息朝我汇聚，外越暗听越细）
7. **衍生之象一步一步推**：结构 → 本象 → 衍生之象，每一步都要说得出"因为什么所以是什么"（离为目 → 看 → 被盯上 → 有人在关注自己的错处）。中间有一步说不出理由就不能取。现代事物也用同一方法推（矫揉为可塑性 → 塑料；坎为通 → 互联网；乾为凝练象征 → logo）。
8. **同一个卦读哪一面，由生克与其他信息共同决定**：同一个巽，被克被泄时读"无根漂泊"，得生时读"向下渗透"（案例三两次梦）。测字、外应给出了方向，就按那个方向读：案例六巽木生体，测字已出"越轨之牛"，巽就要读轻浮多欲，不能只读温和付出。多种方法指向同一面时，这一面才定得下来。
9. **同一象有多处落点时，看哪一卦与体直接作用**：如"虎咬"要两次都作用于体，克体的是兑、只泄体的是离 → 虎落兑（案例三）。不和体发生作用的卦，不承载与体相关的核心之象。
10. **结构推出的象必须过生克关**：结构给出候选象，生克决定取不取、取哪一面。结构对上、生克对不上 → 不取；生克对上、结构推不出 → 属于勉强取象，存疑。

## 十、应期推断法（补充：实现"问时间必答时间"）

应期是本体系对"时间问题必须给出具体答案"的落实，常用方法：

1. **卦数定数**：取变卦的卦数，或全卦数（上下卦卦数之和）配年/月/日/时——先天卦用先天数，后天卦用后天数；配哪一级看具体问题（测最近的工作取日；测婚姻年、月都有可能，结合旺衰交叉验证）
2. **外应提示**：外应场景中出现的时间意象（如日落、季节、钟点）可直接借用
3. **十应人事**：十应中人事应等信息可辅助锁定年、月、日、时辰的落点

各法推出的落点如何取舍（互验取重、全不同以旺衰为准、长久之事看旺衰逐月变化），见 SKILL.md 第五章第8节。

输出时给出明确落点（如"三日之内""本月下旬""子午时"），避免"很快""不久"等模糊表述。

## 十一、杂占 / 射覆要点

- **杂占**（卦主无具体问题，只问"最近如何/发生了什么"）：通常看两种情况——自身与家宅；按体卦特性与有无克体之卦区分（参考[EXAMPLES.md](EXAMPLES.md)案例一）；有克体之卦不能直接判为事在自身，要看具体是什么卦、有无其他征兆，灵活判断；起卦以时间起卦为主，其他起卦方法均可
- **射覆**（猜物，含"我在干什么""我在玩什么"这类猜当下之事）：按阴阳爻结构推出器物的形态、质地（如外坚内柔、中空、上开口），类象表辅助印证，重取象轻断事
  - **射覆直接给答案，不向卦主提问**：射覆是猜，提问等于讨提示，豁免 SKILL.md 总则第7条"先问后断"；起卦后直接推出唯一答案，最多附一个备选象
  - **本象优先**：先取各卦最直接的本象——自然物、实物（坎水、离火、震雷、巽风、艮山、兑泽、坤地、乾天），本象放进问题里说不通，才一步一步推衍生象
  - **分数、数字类射覆直接取卦数**：问分数、金额、数量这类数字，直接按卦数读数，不拿吉凶、旺衰、满分、"正常水平"去推数字高低，也不改读法去凑一个"合理"的数。吉凶是相对卦主本人说的：平时两百分水平考到三百多，同样是用生体的吉。反例：初中总分得山火贲初爻动，实为357分，却因为"体当令、用生体＝成绩好"和"满分750"读成731
  - **不拿自己对卦主处境的猜测去套卦象**：不按"他正在和我对话""现在流行什么"去解卦。反例："我在干什么"得风地观变风水涣，坎就是水（在冲水）、坤土为一摞瓷碗、巽为洁齐（洗、擦），实为洗碗，却被"正在聊天"带偏把坎读成网络；"玩什么游戏"得山泽损变火泽睽，离就是火、震就是雷，实为《火影忍者究极风暴4》，却套"流行射击游戏"把艮读成掩体
