01 / 隐私

密钥只在需要的地方

免费服务的 Key 仅放在 Supabase 服务端，登录后由后端转发。自带 Key 模式直接请求你的接口。聊天不写入本项目数据库，服务商仍可能按其政策留存；不要发送隐私资料。

02 / 兼容

免费与自带 Key 分开

免费服务仅限验证后的 GitHub／邮箱账号，每账号每天 5 次、全站 100 次，不能保证五次内解完一卦。自带 Key 需接口支持跨域和 Chat Completions，不受免费配额影响。

03 / 能力

完整规则，不等于完整工具

四份规则全文随请求加载，建议模型有至少 128K 上下文（64K 可能不足）。历法在本地算，解释由模型生成；没有 OpenCode 的终端、检索工具或真实环境感知，不能自动观察外应。

发送失败、余额消耗或图片无法识别怎么办？

401 / 403：检查密钥和模型权限。404：检查接口路径和模型 ID。429：检查余额、速率和配额。网络错误：可能是 CORS、DNS、TLS 或浏览器限制。上下文不足：换大上下文模型或新开一局；完整规则和历史每轮都会计入输入费用。图片会在本地缩放、重编码后发送给所选服务商，不能保证文字识别无误。取消请求也不代表服务商已停止计费。本页不会自动重试收费请求。
