## 这是什么？

一个面向 AI 智能体的梅花易数技能包，将起卦规则、体用分析、阴阳爻取象、测字、外应与案例整理成可按需读取的 Markdown 文档，并配有时间起卦和干支计算脚本。

本技能出自 **「梅花长手」改编体系**，以邵雍《梅花易数》为底本；部分案例取自野崖《皇极观物心易》，并按本技能的方法重新推演。它是一个有自身约定的整理版本，不代表所有梅花易数流派。

> **核心思路：收集信息 → 提出候选象 → 结构与生克校验 → 多法互证 → 输出白话推演。**
>
> 这是传统术数的文化学习与 AI 提示词实践项目，不是经过科学验证的预测工具。案例反馈不等于预测准确率，文档中的把握分档也不是统计概率；不应用它替代医疗、法律、投资等专业判断。

## 有什么特点？

| 特点 | 具体做法 |
| :--- | :--- |
| **不只报吉凶** | 交代主卦、互卦、变卦、动爻、体卦用卦与关键生克，让过程可以复盘。 |
| **先推结构，再查类象** | 从三爻卦的阴阳、位置、内外、动静、刚柔推导取象，万物类象表仅作提示与辅助印证。 |
| **分清「体」与「体卦」** | 体是问题的核心，体卦是它在卦局中的载体；不机械地把体等同于求问者。 |
| **不套固定吉凶** | 生克结合问题与取象解释；旺衰用于判断程度，不凭「旺」字直接说好。 |
| **规则与计算分工** | Python 负责历法、干支和排卦，AI 按文档负责提问、取象、解释与复盘。 |
| **保留失败与疑问** | 案例记录断错之处、改进路径和未能解释的细节，不只展示成功结论。 |

## 方法一览

### 01 · 起卦：先分清从「数」入手，还是从「象」入手

- **时间起卦**：默认取求问时刻，以农历年月日和时辰起先天卦。
- **测字起卦**：按实际字形的现代笔画与结构起卦，支持独体字、合体字与多字；手写字还要先观察异常笔画。
- **报数起卦**：三个数分别对应上卦、下卦和动爻，主要用于射覆、杂占等场景。
- **后天观物起卦**：遇到奇异、不完整的征兆时，以所见之物及相对方位入卦；方位以求问者面朝方向为基准。

本体系约定：**先天卦不用爻辞；后天卦以动爻爻辞提供取象线索，再回到卦局分析。**

### 02 · 体用：先排卦，再找问题的核心

无动爻的三爻卦为体卦，有动爻的为用卦。但「体是什么」仍需结合问题、征兆与信息来确定：可能是某个人，也可能是家宅、官职、关系或一种状态。

信息不足时，先列出不同的候选象，再通过与卦局紧扣的提问逐步筛选，不直接堆砌结论。

### 03 · 阴阳爻取象：不靠查表贴标签

取象只看**单个三爻卦**，不把六爻叠在一起随意拼形。以离卦为例：

```text
━━━━━━  阳：外实、刚
━━  ━━  阴：中虚、柔
━━━━━━  阳：外实、刚
```

由「外实中虚」提出形态候选，再看具体问题与生克关系是否支持。不是见离就必取火、眼睛或文书，更不能脱离问题把类象全部罗列出来。

### 04 · 主互变与生克：把开始、过程和结果连起来

- **主卦**：事情的开始。
- **互卦**：过程与细节；体互、用互分别偏向自身一侧和外部一侧，作用并不互相隔绝。
- **变卦**：事情的结果，结合体卦来看。

生克用于校验取象之间的关系，而不是套用「生必吉、克必凶」。同样的关系，放进不同问题里可以有不同含义。

### 05 · 测字、外应与应期：让不同线索相互核对

测字观察字形、增减、拆合与手写异常；外应观察求问前后真实发生的现象。线索都要回到原卦局中定位，不另编一套脱离卦局的故事。

若使用模拟外应，必须明确说明是模拟场景，不能冒充真实现象，也不作为独立证据。问到时间时，再结合卦数、字形线索和旺衰变化推应期。

### 06 · 射覆：少绕弯，先读最直接的象

射覆用于猜物、猜正在做的事等场景，**直接给出判断，不追问提示**；自然物、实物的本象优先，不拿对求问者处境的猜测去套象。

分数、金额、数量等数字类问题，以直接取数为思路，不用吉凶推绝对数字高低。例如从两百分进步到三百多分，对当事人也可能是好事。

> 数字的组合与读序仍有待案例检验，本仓库不声称已有一套能稳定推出任意精确数字的通用算法。

## 快速开始

### 安装到 OpenCode

将仓库完整下载并解压，把包含 `SKILL.md` 的文件夹命名为 `shaoyong-suangua`，放到下列任一位置：

| 范围 | 路径 |
| :--- | :--- |
| 全局使用 | `~/.config/opencode/skills/shaoyong-suangua/` |
| 仅当前项目 | `.opencode/skills/shaoyong-suangua/` |

Windows 全局目录通常为 `%USERPROFILE%\.config\opencode\skills\shaoyong-suangua\`。不要只复制 `SKILL.md`，其余参考文件和脚本也要保留。

安装后可直接提问，或明确指定使用 `shaoyong-suangua` 技能。OpenCode 按描述发现技能，再按需加载正文与参考资料。

### 安装计算依赖

在技能目录中执行：

```sh
python -m pip install -r requirements.txt
```

仅阅读文档不需要 Python；使用计算脚本时需要 Python 3.9+ 与 `lunar_python==1.4.8`。

### 运行计算脚本

```sh
# 时间起卦：输出农历、干支、主互变卦、体用、生克和月令/日辰旺衰
python scripts/qigua.py time --dt "2026-10-16 19:37"

# 其他起卦方式：只取历法与干支信息
python scripts/qigua.py ganzhi --dt "2026-10-16 19:37"
```

`--dt` 按北京时间输入。省略时脚本读取系统本地时间，因此仅在系统时区为北京时间时省略；其他地区请显式传入北京时间。脚本只有 `time` 与 `ganzhi` 两种模式，不生成断语。
